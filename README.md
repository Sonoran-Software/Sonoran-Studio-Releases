# Sonoran Studio Releases

Signed desktop installers and updater metadata are published here by Codemagic.

The lightweight LSPDFR integration is built by GitHub Actions from `lspdfr/` and published as a separate prerelease so it does not replace the desktop updater's latest version. It synchronizes emergency lighting, gameplay moments, and supported officer, location, callout, and dispatch data with Sonoran Studio.

The standalone FiveM resource is packaged from `fivem/` and published the same way. It connects a FiveM server to Studio without requiring SonoranCAD.

[Download the latest LSPDFR plugin](https://github.com/Sonoran-Software/Sonoran-Studio-Releases/releases/download/lspdfr-latest/Sonoran-Studio-LSPDFR.zip)

[Download the latest FiveM resource](https://github.com/Sonoran-Software/Sonoran-Studio-Releases/releases/download/fivem-latest/Sonoran-Studio-FiveM.zip)
